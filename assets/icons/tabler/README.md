# Tabler Icons (curated subset)

Icons in `outline/` and `filled/` are from the [Tabler Icons](https://github.com/tabler/tabler-icons) set (MIT licensed), pulled from the `icons/` directory of the upstream repo.

- **Source:** https://github.com/tabler/tabler-icons (MIT License)
- **Set:** 184 outline + 26 filled (210 total), curated to match GeloTech's UI: dashboard, security scan, bloatware, phone mirror, task manager, DNS, accounts, power, and connection actions.
- **File name convention:** `<icon-name>.svg` matches the upstream Tabler name exactly.

The whole `assets/` folder is already bundled into the packaged EXE by the PyInstaller spec (`('assets', 'assets')`), so these icons ship with the app at runtime.
