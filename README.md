# GeloTechTool

Android debloating / security tool for Windows. Scans connected ADB devices,
classifies packages against the merged GeloTech + UAD database, and supports
debloating (disable / uninstall for user / restore), exclusion lists, APK
backup & restore, screen mirroring via scrcpy, and VirusTotal scanning.

## What's in this folder

| Item | Purpose |
|---|---|
| `techtool.py` + `tech_*.py` | Application source (entry point: `techtool.py`) |
| `GeloTechTool.spec` | PyInstaller build spec (onefile, windowed) |
| `GeloTechTool_obf.spec` | PyInstaller spec for the PyArmor-obfuscated build (needs `build/pyarmor_out` from `pyarmor gen`) |
| `gelotech_database_v3.json` | **The package database the tool loads at runtime** (merged UAD + GeloTech, 5,404 packages, deterministic CRC32 IDs) |
| `gelotech_database_v3.min.json` | Same database, compact form |
| `uad_lists.json` | Canonical UAD source data (merge input) |
| `gelotech_database_v2.json` | Legacy v2 database — kept as a fallback only; the loader uses v3 when present |
| `clean_excluded.txt`, `uninstall_excluded.txt`, `sec_whitelist.txt` | Exclusion lists bundled with the app |
| `scrcpy-win64-v3.3.4.zip`, `ApkIconHelper.apk` | Bundled helper resources (screen mirroring, app icon extraction) |
| `adb.exe`, `AdbWinApi.dll`, `AdbWinUsbApi.dll`, `fastboot.exe` | ADB/fastboot tools used at runtime |
| `Drivers/`, `MTK_CDC_Driver/` | USB drivers for device access |
| `gelotech_icon.ico` | App icon (also embedded in the built exe) |
| `dist/` | Build output: `GeloTechTool.exe`, settings file, database copy |

## Running from source

```bash
pip install -r requirements.txt   # or: customtkinter pillow requests pyinstaller
python techtool.py
```

## Building the exe

Standard build (bundles `gelotech_database_v3.json` and all resources):

```bash
python -m PyInstaller GeloTechTool.spec --noconfirm
```

Obfuscated build (requires PyArmor; re-runs `pyarmor gen` into `build/pyarmor_out`
before running `GeloTechTool_obf.spec`).

## Updating the package database

`gelotech_database_v3.json` is the single live database. It is generated by
merging `uad_lists.json` (canonical) with the GeloTech package data. To
regenerate it with new source data:

1. Refresh `uad_lists.json` (and the GeloTech input file, if changed).
2. Re-run the merge pipeline to produce a new `gelotech_database_v3.json`.
3. Replace the database in this folder and in `dist/`, then rebuild the exe
   (see above) so the bundled copy is updated.

The loader (`tech_common.py::load_package_database`) maps the v3 schema into
the tool's internal records: removal levels (`Recommended` / `Advanced` /
`Expert` / `Unsafe`), UAD warnings → `required_by`, GeloTech notes →
`warning`, GeloTech flags `debloated` / `clean_excluded` /
`uninstall_excluded` → the runtime exclusion lists. If `gelotech_database_v3.json`
is missing it falls back to `gelotech_database_v2.json`.
